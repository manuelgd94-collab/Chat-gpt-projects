# Chat-gpt-projects

## Dashboard de cumplimiento semanal (Maximo ERP)

Se agregó una guía completa para diseñar, revisar y operar un dashboard en Excel con actualización diaria desde Maximo ERP:

- Documento: `docs/dashboard_maximo.md`

Incluye:
- Estructura del archivo Excel.
- KPIs clave (cumplimiento, adherencia y curva S).
- Flujo operativo diario de actualización.
- Buenas prácticas de calidad de datos.
- Auditoría práctica con hallazgos y plan de corrección para archivos existentes.
- Protocolo para revisión remota cuando no se puede adjuntar el .xlsx.
- Guía adicional para revisión remota cuando un enlace de Drive/Sheets no puede abrirse.
